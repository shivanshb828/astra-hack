# ECG wearable review assets

- `wearable-assembly.blend`: actual saved KiCad PCB + editable concept enclosure + bare chest reference, with red findings. Lid hidden for inspection; unhide the Removable lid object to close it.
- `ecg-chest-enclosure.blend` / `.glb`: editable concept base, lid, adhesive carrier and electrode discs. Interior 100 × 40 × 7 mm; enclosure exterior 104 × 44 × 10 mm. Complete concept envelope including adhesive/electrodes is 120 × 54 × 10.8 mm.
- `enclosure-base.stl`, `enclosure-lid.stl`: watertight individual solids in millimeters. They have no retention, gasket, fastener, or PCB-mount design; not production-ready.
- `human-chest-reference.blend` / `.glb` / `.obj`: MakeHuman CC0 surface scaled to 1750 mm stature, cropped to a chest region. Representative anatomy, not a patient-specific or physiological model.
- GLB units are meters. Blender/STL/OBJ modeling units are millimeters; GLB reimport tests verify the conversion.
- `assembly-verification.json`: native model coverage, geometric placement checks, source hash and outstanding findings. L1 has no native model; no stand-in was added.
- `engineering-report.md` / `.json`: export of the review timeline, decisions, budgets and evidence at build time. Fresh reports are available from the widget.

Rebuild using Blender background mode with `build_assets.py`, followed by `build_assembly.py`. The assembly builder expects `kicad_bridge/runtime/wearable-assembly-source.json`, generated by the native saved-board exporter. These scripts never replace the live scene.

Open the complete `.blend` normally. To connect that scene to the widget, run the existing `blender_widget/addon.py` in Blender's Python console using `runpy.run_path(path, run_name='__main__')`. The adapter is session-scoped; loading a file alone does not start it.

This is geometry review: no patient protection validation, biocompatibility testing, physiological simulation, diagnostic sensitivity validation, ingress testing, or automatic copper routing is implied.
